# Sample Assets

This directory contains (or will contain) sample files for upload testing.

When the flow scripts run without actual files, they generate placeholder data that mimics the file structure.

## Adding Real Test Files

For more realistic testing, add these files:

- `sample-image.jpg` - A small JPEG image (recommended: < 100KB)
- `sample-document.pdf` - A small PDF document (recommended: < 500KB)
- `sample-video.mp4` - A small video file (recommended: < 1MB)

The upload helper will automatically use these files if present.
